# Höststart: första UI-paketet

Godkänt av användaren 2026-09-07: genomför direkt i befintlig app.

Mål: läsbar mobilnavigation, korrekt foderbesked och direkt åtkomst till hästens
status. Behåll grön design, befintliga routes och dependencies. Ingen schemaändring.

1. Lägg ett Playwright-regressionstest i `scripts/e2e/autumn-ui.spec.mjs` som
   avmarkerar Hö på Saga och verifierar att foderplanen fortfarande visas i listan.
   Lägg även kontroller för synliga tabbetiketter och desktop-bakåtknapp.
   Kör före ändring och bekräfta att felbeteendet fångas.
2. I `app/(tabs)/_layout.tsx`: visa svenska tabbetiketter under ikonerna och
   använd en hästikon från redan installerade ikonpaketet. Behåll fem destinationer.
3. I `components/ScreenHeader.tsx`: rendera explicit vänsterinnehåll även på desktop.
   I `components/Primitives.tsx`: ge textknappar plats efter texten och bevara
   ikonknapparnas form. Verifiera Nytt pass vid 390 px.
4. I `app/(tabs)/stable-horses.tsx`: härled plan/avprickning med `deriveFeedFocus`
   för dagens tre fodringar; Hö-kontrollen ska inte bestämma om plan finns.
   Länka Status till `/horses/${horse.id}`. Reservera 120 px bottenutrymme i
   Hästar, Idag, Schema och Chat. Bevara redigeringsvägen med Hantera hästar.
   Initialisera kalenderns ref med `undefined`.
5. Kör `npm test`, `npm run lint`, `tsc --noEmit`, `npm run build:web` och
   relevanta befintliga demo-e2e plus nya regressioner. Granska mobil/desktop
   visuellt och spara resultat samt QA-script i auditrapporten.

Backendens återstart kontrolleras separat. Live-sparning får inte rapporteras
som verifierad förrän riktiga backendtester faktiskt har passerat.

Genomförd utökning efter återstart: foderkollar i Idag och hästprofilen inväntar
serverbekräftelse, visar Sparar/fältfel och behåller anteckningar vid nätfel.
Inget schema ändras. Regressionstester kördes före och efter fixen; test för
riktig sparning återställer QA-raden efter verifierad omladdning. Passens
konkurrenstest använder Lunch eftersom seedade standardpass tar Morgon/Kväll.
